Why was index.html previously returning the old title?
In earlier versions, merchant/dashboard.html was updated to the modern v4.8 design system, while merchant/index.html was left as the legacy 102KB v4.2 monolithic file. Because standard web servers (IIS, Express, Nginx) default to index.html for directory requests, visiting /merchant/ served the old legacy page. In v4.8, index.html is unified with dashboard.html, ensuring consistent, modern rendering across every web server.
