2. In-Depth Gap Analysis by Functional Domain
Root Cause & Remediation
🚚

Domain 1: Ekart 3PL Logistics & Shipping Automation

Carrier: Ekart Logistics Elite B2B/B2C API · Warehouse: Smeram Primary Hub

85% Completed
✅ Delivered & Verified in Code
  • Instant Auto-Booking: Order creation on payment success/COD automatically triggers zkcEkartCreateShipment() and assigns the AWB without merchant intervention.
  • 2-Way Status & Cancellation Sync: Cancel action issues DELETE /api/v1/package/cancel, updating Ekart to Seller Cancelled. "Sync from Ekart" polls live status.
  • Packaging Bulk Sync: packaging.html allows selecting unpacked orders and syncing them in one shot with ⚡ Sync selected to Ekart.
  • Official 4×6 Thermal Label Integration: Direct streaming of official Ekart barcode shipping labels via /shipments/orders/{id}/label.
⚠️ Remaining Gaps & Roadmap Requirements
  • Ekart Manifest Handover Sheet Generation: In Ekart, booked shipments enter Manifest Pending. While couriers accept individual scans, generating a consolidated daily Manifest PDF for the pickup driver to sign is required for high-volume dispatch.
  • Pre-Order Pincode Serviceability Check: Customers can currently place orders for any 6-digit Indian PIN. A real-time pre-check during checkout against Ekart's serviceable pincode master will prevent booking errors for non-serviceable rural locations.
  • Multi-Courier Failover (Delhivery / Shiprocket): If an address is flagged as non-serviceable by Ekart, the system currently fails. An automated fallback to a secondary courier (Delhivery) should handle unserviceable zones.
🧾

Domain 2: Statutory Tax Invoicing, GST & Accounting

Compliance: Indian GST Act (CGST / SGST / IGST) · HSN 33059040

90% Completed
✅ Delivered & Verified in Code
  • GSTIN Verification: Validates 15-character GSTIN structure, state code (e.g. 33 for Tamil Nadu), and pan-checksum.
  • Place of Supply Engine: Automatically splits into Intra-State (CGST 2.5% + SGST 2.5%) for Tamil Nadu and Inter-State (IGST 5.0%) for other Indian states.
  • Real PDF Engine: Generates vector-sharp PDF tax invoices with store branding, seller signature block, and itemized tax breakdowns.
⚠️ Remaining Gaps & Roadmap Requirements
  • Fiscal Year Sequential Numbering: Current invoices use INV-YYYY-XXXX. A statutory sequential format resetting annually (e.g. SMR/26-27/0001) ensures 100% compliance with audit standards.
  • E-Way Bill Integration: Required by Indian law for single consignments exceeding ₹50,000. Currently not applicable for low-ticket retail orders, but needed for B2B wholesale orders.
  • Accounting Sync (Tally / Zoho Books): Exportable GSTR-1 CSV summary or direct API webhook to push invoices to accounting software.
⚙️

Domain 3: Multi-Environment Deployment & Server Exporter

Target Hosting: GoDaddy cPanel Apache / MySQL · Local: MAMP / Node.js

80% Completed
✅ Delivered & Verified in Code
  • Split Package Architecture: Separate ZIPs for static Frontend (HTML + images) and Backend API (PHP services, configs, SQL).
  • Zero-Guessing Routing: zk-env.js cleanly injects the environment's base URL across 91 frontend files.
  • Subfolder & .htaccess Compatibility: Configured for subfolder hosting with rewrite rules, hiding database and config files.
⚠️ Remaining Gaps & Roadmap Requirements
  • Automated Browser-Side FTP Transport: Currently, the merchant downloads ZIP files and unzips them via cPanel File Manager. An in-browser FTP/SFTP client will allow 1-click deployments.
  • One-Click Production Database Migrator: A database migration runner in the admin portal that runs schema patches on live MySQL without manual phpMyAdmin SQL imports.

Release Schedule

  • Two-way Cancel and Status polling from Ekart API

  • Packer Role Permission: Restricted merchant view specifically for packaging warehouse operators
