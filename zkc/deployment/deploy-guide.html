Step-by-Step Deployment
Complete setup from zero to live store — estimated time: 45 minutes
1
Buy domain on GoDaddy
Search and purchase miliro.in and smeramnaturals.in
⏱ 10 min
  1. Go to godaddy.com → search for miliro.in
  2. Add to cart → complete purchase (₹699–₹999/year for .in)
  3. Repeat for smeramnaturals.in
  4. Do NOT purchase GoDaddy hosting — you already have Hostinger
⚠️
When GoDaddy offers "Website Builder" or "Hosting" during checkout — skip and decline. You only need the domain from GoDaddy. Hosting is on Hostinger.
2
Sign up for Hostinger
Create account and choose the Business plan
⏱ 5 min
  1. Go to hostinger.in → Choose Business Web Hosting
  2. Select 12 or 24 month plan (longer = cheaper per month)
  3. During signup: when asked for domain → select "I already have a domain"
  4. Type miliro.in as your primary domain
  5. Complete payment → you'll get access to hPanel
✅
Hostinger gives you a free SSL certificate — this makes your store load as https://miliro.in (the padlock icon). This is required for customer trust and Razorpay payments.
3
Get Hostinger Nameservers
Find the NS1 and NS2 values to paste in GoDaddy
⏱ 2 min
  1. In Hostinger hPanel → go to Hosting → Manage
  2. Scroll to DNS / Nameservers section
  3. You'll see two nameserver values like:
# Hostinger nameservers — copy these two values
NS1:  ns1.dns-parking.com
NS2:  ns2.dns-parking.com

# Note: your actual values will be specific to your account
# They may look like: ns1.hostinger.com / ns2.hostinger.com
4
Point GoDaddy domain to Hostinger
Update nameservers in GoDaddy DNS settings
⏱ 5 min + 24h propagation
  1. Login to GoDaddy → go to My Products → Domains → miliro.in
  2. Click Manage DNS
  3. Scroll to Nameservers section → click Change
  4. Select "Enter my own nameservers"
  5. Paste the two Hostinger nameserver values
  6. Click Save
  7. Repeat for smeramnaturals.in
⏳
DNS propagation takes 2–48 hours (usually 2–4 hours in India). During this time the domain may not work. This is normal — continue with the next steps while waiting.
What to changeOld value (GoDaddy)New value (Hostinger)
Nameserver 1ns1.domaincontrol.comns1.hostinger.com
Nameserver 2ns2.domaincontrol.comns2.hostinger.com
5
Add domain in Hostinger hPanel
Add miliro.in and smeramnaturals.in to your hosting account
⏱ 5 min
  1. Login to Hostinger hPanel
  2. Go to Websites → Add Website
  3. Enter miliro.in → click Add
  4. Hostinger creates a folder: public_html/miliro.in/
  5. Repeat → Add smeramnaturals.in
  6. Enable Free SSL for both domains (hPanel → SSL → Install)
✅
After adding domains, Hostinger creates separate folders for each website. Files you upload to miliro.in/ folder will show at https://miliro.in. Files in smeramnaturals.in/ will show at https://smeramnaturals.in.
6
Upload store files to Hostinger
Upload miliro-store.html and smeram-store.html via File Manager
⏱ 5 min
  1. In hPanel → go to Files → File Manager
  2. Navigate to public_html/miliro.in/
  3. Delete the default index.html that Hostinger puts there
  4. Click Upload → upload miliro-store.html
  5. Rename it to index.html (right-click → Rename)
  6. Repeat for smeramnaturals.in/ with smeram-store.html → rename to index.html
# Hostinger folder structure — what it looks like
public_html/
├── miliro.in/
│   └── index.html         ← miliro-store.html renamed
│
└── smeramnaturals.in/
    └── index.html         ← smeram-store.html renamed
💡
The file MUST be named index.html — this is what the web server loads when someone visits your domain. Any other name won't work automatically.
7
Enable SSL (HTTPS) for both stores
Free Let's Encrypt SSL — required for Razorpay and customer trust
⏱ 3 min
  1. In hPanel → go to Advanced → SSL
  2. Click Install SSL for miliro.in
  3. Select Let's Encrypt (free) → Install
  4. Enable Force HTTPS redirect (so http:// auto-redirects to https://)
  5. Repeat for smeramnaturals.in
⚠️
Razorpay will not work without HTTPS. Always enable SSL before testing payments. Also, Google ranks HTTPS sites higher — important for SEO.
8
Connect ZKCommerce API (Railway)
Link your store frontend to the ZKCommerce backend API
⏱ 10 min

Your store HTML files need to know where the ZKCommerce API lives. Update this one line in each HTML file before uploading:

// In miliro-store.html and smeram-store.html
// Find this line near the top of the <script> section:

// BEFORE (development):
var API_BASE = 'http://localhost:3000/api';

// AFTER (production — replace with your Railway URL):
var API_BASE = 'https://zkcommerce-api.up.railway.app/api';

// To find your Railway URL:
// Railway dashboard → your project → Settings → Domains
// It looks like: https://YOUR-APP-NAME.up.railway.app
💡
Open the HTML file in Notepad or VS Code, find the line with localhost:3000, replace it with your Railway URL, save, then re-upload to Hostinger.

Ongoing Management After Go-Live
How to update store content, add products, and manage orders
📦
Adding Products
Login to ZKCommerce merchant dashboard → Products → Add New. Set name, price, description, variants (sizes), and upload product images. Published instantly.
🛒
Managing Orders
New orders appear in the dashboard and trigger a WhatsApp alert. Click any order to view details, update status (Processing/Shipped/Delivered), and generate GST invoice PDF.
🖼️
Updating Store Design
Store settings → Appearance. Upload new logo (PNG/SVG), change banner/cover image, update brand colours. Changes apply instantly without any developer needed.
💳
Payments Setup
Settings → Payments → Razorpay. Enter your Razorpay Key ID and Secret. Test with rzp_test_ keys first. Switch to rzp_live_ after KYC is approved at razorpay.com.
📱
WhatsApp Alerts
Settings → Integrations → WhatsApp (Gupshup). Enter API key. Customers get order confirmation, shipping update, and delivery notification on WhatsApp automatically.
🔄
Updating Store Files
When you update the HTML store file — open Hostinger File Manager, navigate to the domain folder, delete the old index.html, and upload the new one. Takes 2 minutes.
